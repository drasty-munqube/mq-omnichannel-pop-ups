It's a plain static HTML page — the point of this demo. The popup you'll see below is being pulled live from your MQ campaigns and rendered here purely by the one <script> tag at the bottom of this file.

This demo page is served from your own app, so the widget script can call /api/widget on the same origin. On a real third-party site, the script tag's src would point at your deployed app's public URL instead of a relative path — nothing else changes.

This block exists only to make the page tall enough to scroll — the live campaign on this demo shop is set to trigger at 50% scroll depth, so keep scrolling.
